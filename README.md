# Бот поиска свободных юзернеймов

Python 3.10+, aiogram 3.

## Запуск
```bash
pip install -r requirements.txt
python main.py
```
Токен и ваш ID уже лежат в `.env`. На Windows/Linux/VPS запускается одинаково; для постоянной работы
используйте systemd/pm2/screen.

## Возможности
- Кнопки: 5/6 букв моментально, 5/6 букв Premium (читаемые слова), в сообщении «Скопировать» и «Дальше».
- Каждый ник проверяется на t.me (+ getChat) и на Fragment (продажа, аукцион, продан).
- Ловушки: до 5 слотов (Premium/админ: 300), проверка каждые 15 минут.
- Автопоиск (Premium): ники нужной цены с Fragment.
- Premium: 150 ⭐ в месяц (автопродлеваемая подписка Stars). Админ (ID 5787410228) получает всё сразу.
- Лимиты обычных пользователей меняются в `config.py` (`LIMITS`, `TRAP_SLOTS`).

## Премиум-эмодзи
Боту нужны ID кастомных эмодзи. Админ отправляет боту сообщение с нужным премиум-эмодзи, бот отвечает
его ID, затем `/setemoji search 5368324170671202286` (имена: `/emojis`). Пока ID не заданы,
показываются обычные эмодзи. Премиум-эмодзи в тексте видны всем пользователям; в подписях кнопок
Telegram их не поддерживает для ботов, поэтому на кнопках обычные.

## Важно
- Токен попал в переписку: сгенерируйте новый в @BotFather (/revoke) и замените в `.env`.
- При большой нагрузке Telegram/Fragment отдают 429. Бот сам делает паузу; для скорости укажите
  `PROXIES` в `.env`.
- Разметка Fragment может измениться: парсеры в `checker.py` (`parse_fragment`, `parse_listing`).
