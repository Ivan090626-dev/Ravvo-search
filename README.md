# Бот поиска свободных юзернеймов

Python 3.10+, aiogram 3.

## Запуск
```bash
pip install -r requirements.txt
python main.py
```
Токен и ваш ID уже лежат в `.env`. На Windows/Linux/VPS запускается одинаково; для постоянной работы
используйте systemd/pm2/screen.

## Возможности
- Кнопки: 5/6 букв моментально, 5/6 букв Premium (читаемые слова), в сообщении «Скопировать» и «Дальше».
- Каждый ник проверяется на t.me (+ getChat) и на Fragment (продажа, аукцион, продан).
- Ловушки: до 5 слотов (Premium/админ: 300), проверка каждые 15 минут.
- Автопоиск (Premium): ники нужной цены с Fragment.
- Premium: 150 ⭐ в месяц (автопродлеваемая подписка Stars). Админ (ID 5787410228) получает всё сразу.
- Лимиты обычных пользователей меняются в `config.py` (`LIMITS`, `TRAP_SLOTS`).

## Заблокированные ники (важно)
Страница t.me и Fragment не отличают свободный ник от заблокированного/зарезервированного Telegram.
Окончательно это знает только Telegram через `account.checkUsername`, поэтому бот использует ваш аккаунт:
1. https://my.telegram.org/apps → создайте приложение, впишите `TG_API_ID` и `TG_API_HASH` в `.env`.
2. `pip install -r requirements.txt` и один раз `python tools/login.py` (номер, код, пароль 2FA).
3. Запускайте `python main.py`. В логе появится «Точная проверка ... включена».
Лучше использовать запасной аккаунт. Telegram ограничивает частоту таких проверок: при FloodWait бот сам ждёт.

## Премиум-эмодзи
Боту нужны ID кастомных эмодзи. Админ отправляет боту сообщение с нужным премиум-эмодзи, бот отвечает
его ID, затем `/setemoji search 5368324170671202286` (имена: `/emojis`). Пока ID не заданы,
показываются обычные эмодзи. По правилам Bot API кастомные эмодзи в сообщениях бота работают только у ботов с купленными
дополнительными юзернеймами на Fragment, иначе Telegram показывает обычные. В кнопках их нет в любом случае.

## Важно
- Токен попал в переписку: сгенерируйте новый в @BotFather (/revoke) и замените в `.env`.
- При большой нагрузке Telegram/Fragment отдают 429. Бот сам делает паузу; для скорости укажите
  `PROXIES` в `.env`.
- Разметка Fragment может измениться: парсеры в `checker.py` (`parse_fragment`, `parse_listing`).

## Обязательная подписка на каналы
Сделайте бота администратором канала, затем (от имени админа бота):
`/addchannel @канал` (приватный: `/addchannel -100… https://t.me/+ссылка`), `/channels`, `/delchannel id`.
Пока пользователь не подписан на все каналы, бот отвечает только просьбой подписаться; подписка проверяется при каждом действии (кэш 30 с). Админы проходят без проверки.
